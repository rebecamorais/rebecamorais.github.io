# Rebs Tech Hub

Repositório do meu site pessoal de documentação técnica, tutoriais e glossário.

🌐 **Acesse em:** [rebecamorais.github.io](https://rebecamorais.github.io)

## Estrutura do Projeto

Este site é construído com **Jekyll** e hospedado no **GitHub Pages**.

- `_tutorials/`: Guias práticos sobre ferramentas e fluxos.
- `_glossary/`: Termos técnicos explicados de forma objetiva.
- `index.md`: Homepage com apresentação e links rápidos.
